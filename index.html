How to Edit Phases & Milestones
  1. Click "Export Settings Template" in the Data tab
  2. Open the downloaded JSON file in any text editor
  3. Find the "experiment" section with "phases" and "milestones" arrays
  4. Edit phase names, day ranges, colors, and milestone icons/labels

Understanding Chapters & Milestones

📖 Chapters

Time periods that divide your experiment into stages (e.g., "Orientation" for Days 1-7, "Adapting" for Days 22-42). Each chapter has a name, end day, color, and motivational message. The app shows which chapter you're currently in.

📍 Milestones

Specific point-in-time markers for events (e.g., "HTMA Test #1" on Jan 6, "Day 42 Check" on Feb 17). These appear as dots on the progress bar and show countdown/days remaining in the experiment tracker.

Milestones

Slider Metrics (−5 to +5)

–5 = top anchor, 0 = in between, +5 = bottom anchor. Only move a slider if you want to track it that day.

Additional Fields (Optional)

Additional fields become extra columns in your log (for things like cramps, palpitations, off-plan, ketones). Use "Choice" for buttons, "Text" for notes, and "Number" for numeric values.
