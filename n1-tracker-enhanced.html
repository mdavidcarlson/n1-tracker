📝 How to Edit Phases & Milestones
  1. Click "📋 Export Settings Template" in the Data tab
  2. Open the downloaded JSON file in any text editor
  3. Find the "experiment" section with "phases" and "milestones" arrays
  4. Edit phase names, day ranges, colors, and milestone icons/labels
  5. Save the file and click "📋 Import Settings Template" in the Data tab

Additional Fields (Optional)

Additional fields become extra columns in your log (for things like cramps, palpitations, off-plan, ketones). Use "Choice" for buttons, "Text" for notes, and "Number" for numeric values.
